# 实验记录：dot-level 期望误差主动校准（2026-11-04）

> 目标：在已有 active dot 校准基础上，加入
> **贝叶斯期望 cm 误差选点**、**特征多样性**、**自适应停止**，
> 并用 subject-level selection/eval 验证泛化性。
>
> 结论先说：
> - **affine 期望误差本身没有超过 feature-diversity/hybrid**；
> - **selection 上的提升没有完全迁移到 eval 被试**；
> - 稳定的收益是 **更少的 dot + 显著更低的 worst**，不是 mean。
> - eval 上 hybrid@20 1.2832 cm（19.1 dot），frame@50 1.2857 cm（24.7 dot）；
>   mean 略好 0.2%，dot 少 23%，worst +12.1% vs +35.0%。

---

## 1. 代码改动

`scripts/calibration/active_calib_sim.py` 新增：

- `_grid_phi`：目标屏幕网格 5×5 的设计矩阵；
- `_trace_err`：当前 affine posterior 在目标网格上的期望误差；
- `_post_update`：观测一个 dot 后的 Bayes 更新；
- `_expected_after`：候选 dot 的期望误差（posterior MC）；
- `select_expected`：序贯主动选点，支持
  - `expected`：全程期望误差；
  - `expected_feat`：前 `n_affine` 个用期望误差，其余用特征 max-min 多样性；
  - `expected_stop`：按期望误差下降停止；
- 新参数：
  - `--session-split {all,select,eval}` + `--session-split-seed`；
  - `--expected-grid`、`--mc-samples`、`--stop-tol`、`--stop-min-dots`；
- detail CSV 新增 `stop_reason`。

所有方法保持：
- candidate/heldout dot 固定切分（65/35），互不重叠；
- 选点只用预测/特征/source prior，不用未选 dot 的标签；
- selected dot 才揭示目标坐标并更新 posterior；
- 校准模型为 norm base + dot-level 残差（DINO16，regions=none）。

---

## 2. 协议

- 模型：`soup_best_ep2_5050.pt`；
- 数据：GazeCapture full test，464 个会话；
- **subject-level split**：按 subject hash 分一半 selection、一半 eval；
  - selection：216 会话；
  - eval：248 会话 / 79 个 subject；
- 每个会话内部 dot 再切 65% candidate / 35% heldout；
- 特征：DINO PCA16；`regions=none`；残差按 dot 均值拟合；
- K_dots = 4, 8, 12, 16, 20；K_frames=50；eval seeds=3。

> 注意：这是 active 模拟协议，不是 A9 的 full-test 协议；
> 绝对数值不能直接和 A9 的 1.1383 比较。

## 5. 结论

1. **affine 期望误差不够**：`expected@20` 和 `random/featdiv` 接近，
   没有超过 `hybrid/featdiv`；base 的 affine 参数很容易识别，选点价值在
   **残差特征覆盖**，不是 affine 参数协方差。
2. **selection → eval 有明显过拟合**：
   - selection：expected_feat@20 1.0842，frame@50 1.0934；
   - eval：expected_feat@20 1.2848，frame@50 1.2857；
   - 优势从 0.9% 缩到 0.07%，说明 selection 上调出来的细节没有泛化。
3. **稳定的收益是 worst 和用户负担**：
   - hybrid@20：19.1 dot vs frame@50 24.7 dot（少 23%），
     mean 1.2832 vs 1.2857（略好），worst +12.1% vs +35.0%；
   - expected_feat@20：mean 1.2848，worst +14.7%；
   - frame@50 的 mean 仍然很强，但 worst 很差。
4. **expected_stop 目前没真正停止**：stop_tol=0.001 太保守，
   实际 dots 仍约 19.1；需要按 residual/feature 的 LOO 收益设停止，
   而不是只看 affine 期望误差。
5. **K=16/12 的负担-精度曲线**：
   - hybrid@16 1.3002（15.6 dot，+12.1%）；
   - expected_feat@16 1.2966（15.6 dot，+17.3%）；
   - expected_feat@12 1.3140（11.8 dot，+16.1%）；
   比 frame@50 多 0.8–2.2%，但 dot 少 37–52%。

## 6. 复现命令

```bash
cd /data1/xieliangcai/code/gazeformer-exps
source /data1/xieliangcai/conda/etc/profile.d/conda.sh
conda activate dl

# selection
nice -n 10 env OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 \
python -u -m scripts.calibration.active_calib_sim \
  --train-npz out/gazecapture/analysis/feats_soup_val.npz \
  --test-npz out/gazecapture/analysis/feats_soup_test_full.npz \
  --index-csv data/GazeCapture/index/index.csv \
  --dino-npz out/gazecapture/analysis/dino_pca16_soup_full.npz \
  --features dino --regions none \
  --methods random,dotcov,featdiv,hybrid,expected,expected_feat,expected_stop,frame \
  --K-dots 4 8 12 16 20 --K-frames 50 \
  --seeds 1 --session-split select \
  --out-dir out/gazecapture/analysis/active_expected_select

# eval（held-out subjects）
nice -n 10 env OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 \
python -u -m scripts.calibration.active_calib_sim \
  --train-npz out/gazecapture/analysis/feats_soup_val.npz \
  --test-npz out/gazecapture/analysis/feats_soup_test_full.npz \
  --index-csv data/GazeCapture/index/index.csv \
  --dino-npz out/gazecapture/analysis/dino_pca16_soup_full.npz \
  --features dino --regions none \
  --methods random,featdiv,hybrid,expected,expected_feat,expected_stop,frame \
  --K-dots 12 16 20 --K-frames 50 \
  --seeds 3 --session-split eval \
  --out-dir out/gazecapture/analysis/active_expected_eval
```

资源：单进程、纯 CPU、2 个 BLAS 线程、nice 10；selection ~4 分钟，eval ~9 分钟，maxrss 1.21GB。

## 8. 下一步

1. **residual-aware expected error**：当前 utility 只服务 affine；
   下一步用残差特征的后验方差/LOO 收益选点，直接服务 residual。
2. **停机规则**：不要只用 affine 期望误差；用 support LOO residual 收益
   或 feature diversity 饱和决定停止。
3. **加 landmark + region**：当前是 DINO-only/regions=none；
   A9 最佳配置含 landmark+3×3 region，active 版应同样比较。
4. **跨 device/orientation 与 RGD**：验证主动策略在新域是否仍减少 dot。
5. **不要把 selection 结论直接写论文**：必须报告 eval 被试；
   当前 selection 的 0.9% 优势到 eval 只剩 0.07%。
