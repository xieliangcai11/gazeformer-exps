## 3. 方法

### 3.1 步骤一：EMA 时序去抖（因果 ✓ 在线 ✓）

\[
s_t=\alpha x_t+(1-\alpha)s_{t-1},\qquad \alpha\in(0,1]
\]
- \(x_t\)：模型预测；\(s_t\)：去抖后预测；\(\alpha=0.6\)（**源域选取** ✓；0.5–0.7 为平台 ✓）
- 依据：注视轨迹连续 ⇒ 相邻帧应接近；模型逐帧抖动远大于目标运动 ✓
- 代价：约 3–4 帧滞后 ✓（实测在本数据"最快速段"也不掉分 ✓；极快场景未测 ✗）

### 3.2 步骤二：全局分位数匹配（1D 最优传输 ✓ 无超参 ✓）

逐轴、逐会话：把**预测**的排序与**计划目标**的排序**逐位对齐**：
\[
y'_i=f(y_i),\qquad f=\text{monotone piecewise-linear}\big(\mathrm{sort}(y),\,\mathrm{sort}(d)\big)
\]
（\(y\) 预测、\(d\) 计划目标；实现为排序后逐位对应 + 线性插值 ✓）

**命题（为什么不需要"配对"）** ✓✓：
> 若错误是**单调**的（大的仍比大的大），则**排序不变**；因此"两个集合排序后逐位对齐"即可复原，**无需知道"哪一帧对应哪个点"** ✓。

- 该命题解释了：为什么方法**只消耗分布信息**、为什么可以无标签 ✓
- 实证支持：相对"4 参数仿射"（同样只吃分布），分位数匹配在 **20/20 会话**上更好 ✓（中位再降 8.7% ✓）

### 3.3 算法框（伪代码）✓

```
输入：会话图像流 {I_t}；计划目标分布 D（App 自己的展示计划，常数或会话级 ✓）
     模型 M；α=0.6（源域 ✓）
1  y_t ← M(I_t)                        # 无标签
2  s_t ← EMA(y_t, α)                   # 因果 ✓
3  D̂ ← quantiles(D)                   # 计划分布（排序）
4  f ← monotone_fit(sort(s), D̂)       # 闭式、无训练 ✓
5  ŷ_t ← f(s_t)                        # 输出
（真值仅在评测阶段用于打分 ✗✓）
```

## 6. 假设与边界（必写 ✓✓）

**6.1 四个假设**
1. 应用**有自己的展示计划**（标定/注视任务 ✓）⇒ 自由观看不适用 ✗
2. 目标轨迹**平滑**（EMA 前提 ✓）
3. 逐会话畸变**近似单调**（映射前提 ✓；实测 20/20 ✓）
4. 用户**依从**（看展示的点 ✓）；本数据集**无法检验** ✗（无眼动仪 ✓）

**6.2 不可识别性（负结果 ✓✓）**
逐会话尺度/偏移**不能**从"观测 + 训练先验"恢复：训练先验 ✗ / IMU-几何 ✗ / 眼框代理（ρ=0.10 ✗）/ 姿态条件先验（+91.6% ✗）/ `dmag` 停步（+2.4%~3.0% ✗）。
⇒ 这解释了为什么必须引入**任务侧信息** ✓。

**6.3 泄漏边界（实测 ✓）**
允许：会话级分布 ✓；禁止：窗口/局部目标 ✗ —— 后者实测把误差"降到"0.65 但**等同逐帧标签** ✓。
