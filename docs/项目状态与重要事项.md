## 2. 数据与预处理

### 2.1 GazeCapture

- 索引：`data/GazeCapture/index/index.csv`（服务器 1,490,911 行 / 1463 名被试）。
- 列：`frame_path, bbox_x/y/w/h, device, screen_w/h, gaze_x/y, cm_px_x/y, imu_x/y/z,
  subject, orientation, split, face_grid_x/y/w/h, dot_num, frame_index`。
- **坐标结论**：4 种 orientation 下图像与人脸均正立，标签与图像坐标系天然对齐 ⇒ **不做旋转**。
- 眼框表：`data/GazeCapture/index/eye_boxes.npz`
  - `boxes [N,8] = 左眼(x,y,w,h) + 右眼(x,y,w,h)`，**原图坐标**；
  - `idx` 必须严格等于 `0..N-1`（数据集会校验）；
  - `filled` 标记兜底/退化帧。
- 眼框生成：分片（连续区间）+ 续跑 + 原子写；体检用 `check_shards --nshards 8`。
- 退化框（<8px，实测 1.79%）：用 `fix_eye_boxes` 以**同被试中位框**替换并置 `filled=True`；
  **禁止镜像**（镜像会把瞳孔水平翻转，引入水平系统偏差）。

### 2.2 RGBDGaze

- 索引 `data/RGBDGaze/index/index.csv`，划分默认**按被试**（`--split subject`）；
- `sample` 模式会跨被试泄漏，仅用于冒烟；
- 索引 bbox 在作者（rot90 后）坐标系，数据集默认 `orient="raw"` 时做反映射；
  `orient="rot90"` 只用于复评历史 ckpt。

### 2.3 设备与 cm 换算

- GazeCapture 用 `tools/data/gazecapture/apple_device_data.csv` 推导每点厘米；
- 设备不在表内 ⇒ `cm_px = NaN` ⇒ 预处理**默认丢弃该帧**（`--keep-nan-cm` 可保留，但会污染角度/cm 指标）；
- **禁止在任何脚本里硬编码屏幕物理尺寸**（曾写死 7.81×16.08cm，导致 34% 非该机型帧的 cm 误差失真 4.5–9.2%）。

## 3. 结果可信度（重要！）

### 3.1 已作废：0.8492 / 0.8533（−42%）✗

- 来源：历史会话中的 inline 脚本（已归档为 `scripts/analysis/_archived_quantile_ttal.py`）。
- 做法：每个会话把**预测**按名次映射到**该会话全部真值坐标排序后的列表**：
  `lx = sorted(r["label_x"] for r in rs)`。
- 复现脚本 `scripts/analysis/reproduce_ema_quantile.py`：该做法可逐位复现
  1.0337（无 EMA）/ 0.8492（α=0.5）/ 0.8533（α=0.6）。
- 用**真正事先可知**的目标分布则无法达到：
  | 目标分布来源 | 结果 |
  |---|---|
  | App 设计网格（无标签） | 1.1965–1.394 |
  | 源域 p1/p10 标签分位（合法先验） | 1.193–1.241 |
  | **该会话测试标签分位（oracle）** | **0.8492** |
- 结论：**按测试标签泄漏处理，不得再引用**；只能作为 oracle 上界。
- 已在 `out/rgbdgaze/analysis/HANDOFF.md` 与 `docs/方法章节草稿_2026-10-19.md` 顶部写入更正横幅。

### 关键语义

- **几何 token** = `[短边/长边, log(短边cm), log(长边cm)]`（横竖屏同一语义；竖屏与旧定义一致）。
- **几何随机化**：按标签反推可行尺寸，生效率≈100%；重投影后必须同步替换 `screen_cm`。
- **增强可复现**：逐样本种子 `(aug_seed, epoch, idx)`；`persistent_workers=False` 保证 `set_epoch` 生效。
- **眼框**：`(x,y,w,h)` 原图坐标；行数/`idx` 与索引严格对齐，否则数据集直接报错。
- **TTA 无标签约束**：`--prior-mode session|blend` 必须显式 `--oracle-targets`；否则报错。
- **`--use-imu`**：索引必须有 `imu_x/y/z`；RGBDGaze 没有 ⇒ 直接报错（不再静默零向量）。
- **自动 tag**：包含行为相关参数（geom/eye/seed/lr/bs/epochs…），避免覆盖同一 `best.pt`。

## 5. 常用命令

```bash
# 环境
conda activate dl

# 数据验证（服务器全量）
python -m tools.data.gazecapture.verify --json out/gazecapture/analysis/verify.json

# 眼框：生成 / 体检 / 修复
python -m tools.data.gazecapture.build_eye_boxes_mp --shard 0 --nshards 8
python -m tools.data.gazecapture.build_eye_boxes_mp --merge data/GazeCapture/index/eye_boxes_shard*.npz \
    --out data/GazeCapture/index/eye_boxes.npz
python -m tools.data.gazecapture.check_shards --nshards 8
python -m tools.data.gazecapture.fix_eye_boxes --dry-run
python -m tools.data.gazecapture.fix_eye_boxes          # 原地修复（自动备份 eye_boxes.raw.npz）

# 训练（GazeCapture 预训练；6 卡示例，长任务用 tmux）
tmux new -s train
CUDA_VISIBLE_DEVICES=1,2,3,4,5,6 torchrun --standalone --nproc_per_node=6 \
  -m scripts.train --dataset gazecapture --resolution 224 --no-geom --geom-randomize 0 \
  --augment --aug-shift 0.05 --aug-scale 0.05 --aug-rotate 0 --unfreeze 12 --diff-lr \
  --lr 2e-4 --batch-size 32 --num-workers 8 --epochs 5 --seed 0 --tag gc_run1

# 产物
out/<dataset>/ablation/checkpoints/<tag>/{best.pt,train_args.json}
out/<dataset>/ablation/logs/
```

**资源纪律**：训练与数据生成不要同时打满同一块磁盘/CPU；多进程分片时先看 `load` 与 `iostat`；
后台任务用 tmux/nohup，不要把前台 SSH 卡死。
