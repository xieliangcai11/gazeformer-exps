# 论文骨架（方案 A，2026-10-18）

> 核心叙事：**注视个性化的瓶颈是"信息"而不是"估计器"** —— 我们用三档信息条件（无目标信息 / 目标刺激日志 / 持续标签）分别量化了可达精度，并给出**不可识别性**的边界论证，最后给出各档的推荐方法。

## 2. 实验设置（写清口径，避免审稿人抓 ✗）

- 模型：DINOv2 ViT-S + 眼支流 + 线性头（224，`eye224_mgpu`）
- 划分：RGBDGaze 按被试 8:1:1（test = 5 被试 / 20 会话 / 11031 帧）
- **基线：1.4718 cm（帧加权）/ 1.7333（会话等权）** ✓✓（两种聚合都必须报 ✓）
- 指标：屏幕欧氏误差（cm）、角度误差、>3cm 尾部、逐会话最差
- 关键提醒：**子集（如 p11/p33 的 8 会话）偏易**（帧加权 1.2316 ✗）⇒ 不得与 20 会话数字混用 ✗

## 6. 局限（主动写 ✓）

- 无标签路线**只能改进方差/保守性**，不能修尺度/偏移 ✓（C3）；
- 因果在线设定下，现有无监督 TTA **完全弃权** ✗ ⇒ 这是**领域层面的问题**，不是实现问题 ✓；
- 目标日志档依赖"用户确实看了所展示的点"（依从性 ✓，本数据集无法检验 ✗）。

## 7. 与已有文献的定位

- TTA（Tent/SHOT/DUA/MetaTTA 等）：多为分类/分割，**回归+类别先验失配**的情形缺少审计 ✓；
- 个性化注视（MetaPrompt/AAAI'24、Alfa/AAAI'26）：**无标签**但未量化"无标签能做到什么" ✓；
- 本文贡献 = **把"信息 vs 可达精度"量化 + 边界论证 + 三档推荐方法** ✓（不主张新网络结构 ✓）。
