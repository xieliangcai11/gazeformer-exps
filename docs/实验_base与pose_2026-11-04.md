# 实验记录：base 容量 / 支持点预算 / pose 特征（2026-11-04）

> 目标：主动选点（用户注视更少的 dot）把 **active held-out subject**
> 的 cm 误差压到 **1.0 以下**。
>
> 结论先说：
> - base 的 full（6 参数含交叉项）和更强 prior **都更差**；
> - axis base 仍是最好，`n_affine=4/6/8` 基本打平；
> - pose 8 维在 active 上没有超过 landmark；
> - 目前 **没有任何 held-out active 配置低于 1.0**；
> - selection 上最好也只有 **1.0700**（pose K40，31.3 dot），且 eval 复现不了。
> - 以现有模型/特征，1.0 不是靠选点或 base 能到的；需要模型/特征/训练层面改进。

---

## 1. 代码改动

`scripts/calibration/active_calib_sim.py`：

```text
--base-mode axis|full|quad
  axis : x'=sx*x+bx, y'=sy*y+by（旧基线，4 参数）
  full : x'=a*x+b*y+c, y'=d*x+e*y+f（6 参数）
  quad : 增加 x^2, xy, y^2（12 参数）
--base-prior-scale
--pose-npz
--features 支持 dino,landmark,pose
```

实现：

```text
fit_base / apply_base / build_base_prior
```

- axis 逐位复现旧 `fit_huber`（已用合成数据和新旧函数对比，max 差 <1e-12）；
- full/quad 的 source prior 来自 source 会话拟合参数的协方差；
- 每行 detail 增加 `base_mode`；
- 启动日志打印 base mode、prior mean/sd；
- 所有正式运行写 `*.log`。

### 修过的 bug

新 `fit_base` 第一版在 axis 模式下把同一个 `[x,1]` 设计矩阵同时用于 x/y，
导致 y 轴用 x 坐标拟合，base 变成 1.99 cm（比 raw 还差）。
修复为 axis 每轴使用自己的设计矩阵；full/quad 不受影响。

## 7. 为什么 1.0 目前不可达

1. **base 已饱和**
   - axis base active ~1.30–1.32；
   - 全 2D/二次项过拟合；
   - source prior 加强更差；
   - n_affine 4/6/8 无差异。

2. **residual 增益只有约 0.03–0.04 cm**
   - active base 1.31 → cal 1.27；
   - 即使 residual 完美，也到不了 1.0。

3. **选点不是主要瓶颈**
   - 不同 selection 在同等 dot 下差异通常 <0.01 cm；
   - 加大 K 到 31 dot 也只到 1.2639；
   - selection 1.07 与 eval 1.27 之间有 subject split 泛化差距。

4. **模型/特征上限**
   - full-test A9 soup 1.1383；
   - active raw 1.71，base 1.20–1.32；
   - 要 1.0，需要 raw/base 或特征模型本身下降约 12–21%。

## 8. 下一步（如果必须冲 1.0）

优先做模型/特征，不是继续调选点：

1. **更强视觉特征**
   - DINO PCA32/64（当前 16 维可能压缩过度）；
   - 或全 DINO patch/CLS 特征 + 更强正则；
   - 需要重新导出/训练，不是 active sim 一个小改动。

2. **模型层**
   - 多 checkpoint ensemble / TTA；
   - 更高分辨率、更多训练、eye/face 融合；
   - 只有 raw 降下来，calibrated 才可能到 1.0。

3. **校准标签预算**
   - K40/50 的 active 仍 >1.26；
   - 加标签只能小幅降，不足以单独到 1.0。

4. **评测口径确认**
   - full-test A9 1.1383；active 20 dot 1.2812；
   - 1.0 是 full-test 还是 active held-out？两者差距很大。
   - stride10 预览 1.0174 不可与 full-test/active 直接比较。

5. **不要再用 selection 排名当结论**；
   所有配置必须 held-out subject + 配对 CI。
