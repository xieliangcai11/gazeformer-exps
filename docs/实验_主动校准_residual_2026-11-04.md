# 实验记录：residual-aware dot 主动校准（2026-11-04）

> 目标：在 active dot 校准里，不再只对 affine 做 Bayesian 选点，
> 而是让后续选点直接服务 **dot-level 残差模型**；同时加入
> **相对初始残差误差的停止规则**，并在 subject-level selection/eval 上验证。
>
> 结论先说：
> - **residual D-optimal 不是稳定的平均精度提升**；
> - DINO-only eval 上 `resid@20` 名义最低，但和 `hybrid/featdiv/expected_feat`
>   的逐会话配对 bootstrap CI 全部跨 0；
> - landmark+3×3 上 `resid@28` 与 `expected_feat@28` 基本打平；
> - 稳定收益仍然是 **更少 dot / 更低 worst**，且 `hybrid/featdiv` 也能做到；
> - selection 排名会误导：DINO-only selection 上 `resid` 不如
>   `expected_feat`，到 eval 反而名义略好。**不能只报 selection。**
>
> 本记录是探索性结果，不是论文最终结论。

---

## 1. 方法：选择什么

原 `expected` 只服务 affine：

```text
utility = 目标网格上的 affine 期望 cm 误差下降
```

新方法 `resid`：

1. 前 `n_affine=4` 个 dot 仍用 affine 期望误差选；
2. 用这 4 个 dot 拟合 base，得到 dot-level 残差 `r = label - base(pred)`；
3. 对 candidate dot 的 **base 特征**（DINO / landmark）做标准化；
4. 残差权重 `w` 用 Gaussian 先验，后验精度 `Lambda`；
5. 对每个候选 dot，计算加入它之后，在**未选 candidate dot 特征分布**上的
   残差预测误差下降：

```text
reduction = ||Z_t Lambda^{-1} z||^2 / (sigma_r^2 + z^T Lambda^{-1} z)
```

6. 每选一个 dot，用实际残差更新一次 `Lambda`；
7. `resid_stop` 在 `reduction < stop_tol * 初始残差误差`
   且 support ≥ `min_support` 时停止。

特征标准化在 **candidate** 上做，不使用任何 target label；candidate/heldout
dot 不重叠；只对已选 dot 揭示 target。

代码：

```text
scripts/calibration/active_calib_sim.py
  _standardize_dot_features
  select_residual
  --methods resid,resid_stop
  --resid-stop-tol
  --resid-noise-frac
  --resid-min-support
```

### 1.1 一个必须记录的维度约束

```text
DINO-only:        D=16  -> prepare_features 至少 10 个 support dot
DINO+landmark:    D=37  -> 至少 max(10, 37//2)=18 个 support dot
```

因此 landmark 实验在 K=12/16 时 `calib == base`，残差模型根本没有启用
（detail 里 `note=prep_none`）。landmark 只在 K≥20 有意义。

## 2. 协议

- 数据：GazeCapture，`feats_soup_test_full.npz`，464 个会话；
- subject split：按 subject hash 切 selection/eval；
  - selection：216 会话 / 70 subjects；
  - eval：248 会话 / 79 subjects；
- dot split：candidate 65% / heldout 35%；
- selection 只用候选 dot；heldout dot 不参与选点；
- 每会话一个固定 candidate/heldout 切分；
- 指标：`calib_cm`，按 heldout frames 加权；
- base：per-axis Huber + source prior；
- residual：dot-level ridge，LOO 选 λ，target 标准化；
- DINO-only：`dino_pca16_soup_full.npz`，regions=none；
- landmark：`lm_gc_test.npz`，regions=3×3；
- selection seeds=1；eval seeds=3；
- 绝对数值是 active dot 协议，不可直接和 A9 full-test 的 1.146 比较。

资源：单 CPU 进程，2 个 BLAS 线程，maxrss≈1.22GB，未使用 GPU，<75%。

## 3. DINO-only 结果

### 3.1 Selection（216 会话）

| 方法 | dots | base cm | calib cm | 相对 base | worst |
|---|---:|---:|---:|---:|---:|
| frame@50 | 24.3 | 1.1178 | 1.0934 | −2.18% | +36.17% |
| expected_feat@20 | 19.1 | 1.1153 | **1.0842** | −2.79% | +9.93% |
| hybrid@20 | 19.1 | 1.1126 | 1.0863 | −2.37% | +31.82% |
| featdiv@20 | 19.1 | 1.1174 | 1.0881 | −2.62% | +13.48% |
| resid@20 | 19.1 | 1.1199 | 1.0909 | −2.59% | +12.40% |
| resid_stop@20 | 18.5 | 1.1196 | 1.0904 | −2.60% | +14.40% |
| resid@16 | 15.5 | 1.1268 | 1.1007 | −2.31% | +12.39% |
| resid_stop@16 | 12.6 | 1.1370 | 1.1125 | −2.16% | +15.67% |

selection 上 `resid` 没有超过 `expected_feat`；但 worst 比 frame 好很多。

### 3.2 Eval（248 会话 / 79 subjects，seeds=3）

| 方法 | dots | base cm | calib cm | 相对 base | improved | worst |
|---|---:|---:|---:|---:|---:|---:|
| frame@50 | 24.7 | 1.3263 | 1.2857 | −3.07% | 589/744 | +35.01% |
| **resid@20** | 19.1 | 1.3196 | **1.2812** | −2.91% | 567/744 | +12.10% |
| hybrid@20 | 19.1 | 1.3186 | 1.2832 | −2.68% | 555/744 | +12.10% |
| featdiv@20 | 19.1 | 1.3201 | 1.2840 | −2.73% | 561/744 | +13.11% |
| expected_feat@20 | 19.1 | 1.3194 | 1.2848 | −2.62% | 555/744 | +14.73% |
| resid@16 | 15.6 | 1.3293 | 1.2931 | −2.73% | 566/744 | +14.30% |
| expected_feat@16 | 15.6 | 1.3296 | 1.2966 | −2.48% | 552/744 | +17.25% |
| resid_stop@16 | 12.6 | 1.3423 | 1.3077 | −2.58% | 544/744 | +16.52% |
| expected_feat@12 | 11.8 | 1.3432 | 1.3140 | −2.18% | 523/744 | +16.11% |

`resid@20` 是名义最低，但优势只有约 0.28%。

### 3.3 逐会话配对 bootstrap（248 会话，10k resamples）

| 比较 | 平均差（cm） | 95% CI | resid 胜率 | 中位差 |
|---|---:|---|---:|---:|
| resid@20 − hybrid@20 | −0.00204 | [−0.00740, +0.00315] | 0.512 | ~0 |
| resid@20 − featdiv@20 | −0.00254 | [−0.00778, +0.00237] | 0.464 | ~0 |
| resid@20 − expected_feat@20 | −0.00275 | [−0.00757, +0.00192] | 0.476 | ~0 |
| resid@20 − frame@50 | −0.00137 | [−0.00976, +0.00740] | 0.488 | +0.00082 |
| resid@20 − expected_feat@16 | −0.01224 | [−0.01837, −0.00623] | 0.565 | −0.00366 |
| resid_stop@16 − expected_feat@12 | −0.00666 | [−0.01442, +0.00063] | 0.452 | +0.00067 |

结论：

- `resid@20` 与 20-dot 基线/50-frame 基线的差异**不显著**；
- 显著差异只出现在“resid@20 vs 更少 dot 的 expected_feat@16”，
  但那是 dot 数不同，不是同等预算优势；
- `resid_stop@16` 与 expected@12 的差异也不显著。

### 3.4 分朝向

`resid@20` 在 ori1/2/4 略好，ori3 不如 featdiv/frame：

```text
ori1  1.2729  vs hybrid 1.2747 / featdiv 1.2716 / frame 1.2789
ori2  1.6189  vs hybrid 1.6178 / featdiv 1.6303 / frame 1.6527
ori3  1.2393  vs hybrid 1.2471 / featdiv 1.2442 / frame 1.2372
ori4  1.2477  vs hybrid 1.2456 / featdiv 1.2516 / frame 1.2493
```

没有跨朝向一致的优势。

| 比较 | 平均差（cm） | 95% CI | resid 胜率 |
|---|---:|---|---:|
| resid@28 − expected_feat@28 | +0.00104 | [−0.00174, +0.00395] | 0.476 |
| resid@28 − hybrid@28 | +0.00047 | [−0.00247, +0.00344] | 0.468 |
| resid@28 − frame@50 | −0.01200 | [−0.01947, −0.00408] | 0.605 |
| expected_feat@28 − frame@50 | −0.01304 | [−0.02038, −0.00548] | 0.589 |
| resid@24 − expected_feat@24 | +0.00239 | [−0.00098, +0.00588] | 0.468 |
| resid_stop@20 − expected_feat@20 | +0.00373 | [−0.00042, +0.00792] | 0.448 |

结论：

- `resid@28` 和 expected/hybrid 的差异**完全不显著**；
- 它比 frame 显著好，但 expected_feat 也比 frame 显著好，
  所以不能把“比 frame 好”归因于 residual 选点；
- K24/28 的 selection 领先没有在 eval 复现。

## 5. 总结

1. **residual-aware D-optimal 不是稳定的 mean 提升**。
   DINO-only 名义最低但配对 CI 跨 0；landmark K28 基本打平。
2. **selection 排名不可靠**。
   DINO-only：selection `resid@20` 1.0909 < `expected_feat@20` 1.0842；
   eval 反而 `resid@20` 1.2812 > `expected_feat@20` 1.2848。
   landmark：selection K24/28 residual 领先，eval 没有。
   这再次说明必须在 held-out subject 上报。
3. **稳定的是用户负担和 worst**。
   - DINO-only `resid@20`：19.1 dot vs frame 24.7 dot，worst +12.1% vs +35.0%；
   - 但 `hybrid@20` 同样 19.1 dot、worst +12.1%、mean 1.2832，
     所以 residual 不是唯一来源。
4. **停止规则修正后可用，但收益有限**。
   - 旧规则“相对当前 err0”永远追不上，改成“相对初始 err0 + min support”；
   - DINO-only 停在约 12.6 dot，cal 1.3077；
   - landmark 停在约 18.9 dot，cal 1.2847；
   - 都低于 full K 的均值，和同等 dot 的 expected_feat 差异不显著。
5. **landmark 的维度约束**：
   D=37 需要至少 18 个 support；K12/16 的 landmark “residual” 实际是
   base-only，不能当成 residual 结果。
6. 当前最稳妥的论文表述：
   > dot-level active calibration 能显著减少标定注视点并压低 worst-case，
   > 但 residual-aware D-optimal 本身没有稳定的平均精度增益；
   > feature-diversity / hybrid 是同等或更好的简单基线。

## 8. 下一步

1. **不要把 residual D-optimal 写成主要创新点**；它是负结果/消融。
2. 如果继续做 mean，优先 **hybrid/feature-diversity**，并做
   **同等 dot 预算**的配对检验；不要只比 frame。
3. 若坚持 residual，先解决 **特征维度 vs 标定点数**：
   - landmark 37 维至少 18 support；
   - 可做 source-level PCA / 特征子集，但必须固定后验再评估。
4. 论文主结论应围绕：
   - dot-level 多帧；
   - subject/context 校准；
   - 更少 dot 的 worst-case 稳定性；
   - 所有结论在 held-out subject 上配对报告。
5. 下一步更有价值的是 **RGD/跨设备**和 **landmark+region 的 active 版**
   在相同 dot 预算下的置信区间，而不是继续调 residual utility。
