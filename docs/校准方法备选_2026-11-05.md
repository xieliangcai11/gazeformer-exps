# 校准方法备选（2026-11-05）

> 本文保存除“Calibration Posterior Adapter”之外的其他校准思路，供后续选择。
> 原则：先 val 开发，test 只评一次；support/query 点不重叠；按 subject 分 source/eval。

---

## 1. Gaze Decomposition Calibration

### 思路

将 gaze 预测拆成：

```text
用户相关偏移 + 视线相关成分
```

校准只估计用户相关的 offset / scale / rotation，而不是重新学习整张图到 gaze 的映射。

### 为什么可能有效

- 校准参数少，K 小时更稳；
- 物理意义明确；
- 可以用“中心点估计 offset、边缘点估计 scale”的主动选点策略；
- 不容易像全参数 adapter 那样过拟合。

### 闭环选点

```text
中心区域点 → 估计 offset
边缘区域点 → 估计 scale / rotation
根据当前参数不确定性选择下一个区域
```

### 风险

- 如果真实误差不是 offset/scale 结构，效果有限；
- 需要区分“用户偏移”和“模型预测误差”。

### 相关参考

- Chen & Shi, *Offset Calibration for Appearance-Based Gaze Estimation via Gaze Decomposition*, WACV 2020.  
  DOI: https://doi.org/10.1109/wacv45572.2020.9093419

## 2. Neural Process Calibration

### 思路

把校准看成条件神经过程：

```text
support 点 = 观测
query 图 = 目标
输出：query gaze 的均值 + 方差
```

训练目标使用负对数似然，而不是只做点估计。

### 为什么可能有效

- 直接建模不确定性；
- 闭环选点可以选“能最大程度降低 query 方差”的点；
- 不需要显式 affine base；
- 对少点校准更自然。

### 闭环选点

```text
对每个候选点估计：
加入后 query 预测方差下降多少
→ 选下降最大的点
```

### 风险

- 需要足够 source episodes；
- 方差估计容易校准不良；
- 训练比 ridge 复杂。

## 3. Retrieval-Augmented Calibration

### 思路

从 source 用户中检索相似用户/会话：

```text
用户图片特征
→ 检索相似 source 校准 profile
→ 作为初始校准先验
→ 用少量真值点修正
```

可检索：

- 设备/朝向；
- 头部姿态；
- 眼部外观；
- 误差模式。

### 为什么可能有效

- 冷启动不需要从零；
- 少点校准更稳；
- 和“全局平均先验”不同，它是个性化检索。

### 闭环选点

```text
当前 support 后重新检索
→ 更新先验
→ 选下一个点
```

### 风险

- 检索特征需要可靠；
- source profile 覆盖不足时收益有限。

## 4. Risk-Sensitive / Conformal Calibration

### 思路

不再只优化平均误差，而是优化：

```text
90% 分位误差
最差 10% 用户平均误差
```

或者用 conformal prediction 输出误差区间：

```text
校准后误差 ≤ q 的置信区间
```

### 为什么可能有效

- 直接针对最差用户；
- 对交互/安全场景更有意义；
- 可以回答“这个用户校准是否可靠”。

### 闭环选点

```text
选能最大程度缩小 conformal 区间
或降低 worst 分位误差的点
```

### 风险

- 需要足够标定点估计分位数；
- 可能牺牲平均误差。

## 5. Multi-Fidelity Calibration

### 思路

动作不只是“选哪个点”，还包括：

```text
在这个点多看几帧
还是换一个新点
```

### 为什么可能有效

- 新点：覆盖新区域，成本高；
- 多帧：降噪，成本低；
- 如果当前只是噪声大，多帧比换点更划算。

### 闭环决策

```text
动作 = (点, 帧数)
收益 = 最终误差下降
成本 = 用户注视时间
```

### 风险

- 需要真实交互时间模型；
- 数据集里的 dwell time 与真实 UI 不一定一致。

## 6. Test-Time Prompt / Adapter 基线

### 思路

参考 test-time prompt tuning：

- 冻结主干；
- 只更新极少量 prompt/adapter；
- 用无标签目标数据或少量标签适配。

### 为什么作为基线

已有工作表明少量参数就能做 gaze 个性化，但大多是无标签/域适配场景。

### 相关参考

- Liu et al., *Test-Time Personalization with Meta Prompt for Gaze Estimation*, AAAI 2024.  
  DOI: https://doi.org/10.1609/aaai.v38i4.28151
- Wu et al., *TTAGaze: Self-Supervised Test-Time Adaptation for Personalized Gaze Estimation*, IEEE TCSVT 2024.  
  DOI: https://doi.org/10.1109/tcsvt.2024.3412243
- Wang & Yin, *Test Time Prompt Tuning for Domain Adaptive Gaze Estimation*, ICASSP 2025.  
  DOI: https://doi.org/10.1109/icassp49660.2025.10888165

## 7. 评估协议

所有备选方法都必须：

```text
source 训练 / val 选方法 / test 只评一次
support 与 query 点不重叠
按 subject 分 source/eval
报告 mean、worst、点数
```

基线：

- 当前 affine + residual；
- random/coverage 选点；
- 闭环/批量对照；
- 多 checkpoint 验证。
