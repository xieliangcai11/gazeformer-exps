# 实验记录：dot-level 主动校准（第一版，2026-11-03）

> 目标：回答“系统主动选注视点，能否用更少的 dot 达到当前 frame-level K=50 的精度”。
>
> 结论：**可以，但主动策略必须是 feature-diversity / hybrid，而不是只做 affine D-optimal。**
> 主推 **hybrid@20**：19.1 个 dot、1.1986 cm、worst +13.3%；
> 对比 frame@50：24.5 个 dot、1.2045 cm、worst +41.0%。
> 平均最低的是 featdiv@20：1.1976 cm，但 worst +22.8%。
>
> 注意：本实验是**离线模拟 + 探索性**，超参（n_affine、cov_weight、DINO-only）
> 还没有做 subject-level selection/eval 划分；论文前必须补。

---

## 1. 为什么按 dot 而不是 frame

full test 每个会话（subject+orientation）：

| 统计 | 值 |
|---|---:|
| 平均 dot 数 | 56.6 |
| 中位 dot 数 | 57 |
| 平均 frames/dot | 6.95 |
| 当前 K=50 帧对应的唯一 dot（均值） | 32.3 |
| K=20 帧对应的唯一 dot（均值） | 16.8 |

所以当前固定的 K=50 帧，用户实际要看约 **32 个点**。主动选点应该按 dot 计，
并且一个 dot 可以采集多帧，用户不需要重复看同一个点。

---

## 2. 模拟协议

- 每个会话把帧按 `dot_num` 聚成 dot；
- dot 的目标坐标用该 dot 所有帧的 `label` 均值近似
  （真实系统里显示点坐标是已知的，不需要近似）；
- 每个会话把 dot 固定切成 **candidate 65% / heldout 35%**：
  candidate 用于主动选点，heldout 只用于评估；两者不重叠，避免标签泄漏；
- 所有方法评估同一批 heldout dot 的帧；
- 校准模型：norm base（per-axis Huber + source prior）+ dot-level 残差
  （DINO16；小 K 时 `regions=none` 以降低维数）；
- 残差按 dot 均值拟合：有效样本数 = dot 数，避免同 dot 多帧被当成独立样本；
- 目标函数/评价：heldout 帧的 cm 误差，按帧数加权。

> 本协议与 A9 的 full-test 协议不同：A9 评估所有 heldout 帧；这里只评估
> heldout dots，且 candidate/heldout 固定切分，所以绝对数值不能直接与 A9 的
> 1.1461 比较；表内方法之间的比较是公平的。

---

## 3. 选择策略

| 方法 | 说明 |
|---|---|
| `random` | 从 candidate dot 随机选 |
| `dotcov` | 在 dot 预测位置上做 3×3 coverage |
| `dopt` | 贝叶斯 D-optimal：最大化 affine 参数信息增益 |
| `doptcov` | D-optimal + 空间覆盖/多样性惩罚 |
| `featdiv` | 前 `n_affine=4` 个点用 dot coverage；其余按特征空间 max-min 距离补点 |
| `hybrid` | 前 4 个点用 D-optimal+coverage；其余按特征空间 max-div 补点 |
| `frame` | 当前 frame-level 基线：从 candidate 帧里按 3×3 coverage 选 K 帧 |

`featdiv`/`hybrid` 是这轮的关键：affine 参数很容易识别，选点价值在**残差模型的
特征覆盖**，不是 affine 参数协方差。

---

## 4. 主结果（seeds=3，464 会话，DINO-only，dot-level 残差）

| 方法 | 点预算 | 实际 dot | 实际帧 | calib cm | 相对 base | improved | worst |
|---|---:|---:|---:|---:|---:|---:|---:|
| frame | 50 帧 | 24.5 | 48 | 1.2045 | −2.83% | 1050/1392 | +41.0% |
| random | 20 | 19.1 | 139 | 1.2040 | −2.52% | 1016/1392 | +29.0% |
| dotcov | 20 | 19.1 | 140 | 1.2024 | −2.62% | 1005/1392 | +20.6% |
| featdiv | 20 | 19.1 | 137 | **1.1976** | −2.71% | 1029/1392 | +22.8% |
| **hybrid** | **20** | **19.1** | **136** | **1.1986** | **−2.76%** | 1020/1392 | **+13.3%** |
| hybrid | 16 | 15.5 | 110 | 1.2102 | −2.58% | 1014/1392 | +14.7% |
| hybrid | 12 | 11.8 | 82 | 1.2274 | −2.23% | 975/1392 | +14.2% |

`improved` 是 seed 级计数（464 会话 × 3 seeds = 1392）。

读法：

- **hybrid@20** 比 frame@50 **少 22% 的 dot**，calib 低 0.5%，worst 从 +41% 降到 +13%；
- **hybrid@16** 比 frame@50 少 37% 的 dot，calib 高 0.5%，worst +15%；
- **hybrid@12** 比 frame@50 少 52% 的 dot，calib 高 1.9%，worst +14%；
- `featdiv@20` 平均最低（1.1976），但 worst 比 hybrid 差（+22.8% vs +13.3%）；
- **纯 affine D-optimal（dopt）没有优势**：base 层面 random/dotcov 已经足够，
  选点价值在残差特征的多样性。

base-only 对照也说明这一点：

| 方法 | dot | base cm |
|---|---:|---:|
| random@20 | 19.1 | 1.2324 |
| dotcov@20 | 19.1 | 1.2338 |
| dopt@20 | 19.1 | 1.2370 |
| frame@50 | 24.5 | 1.2396 |

D-optimal 甚至略差于 random/coverage；dot-level 的 base 优势主要来自
“一个 dot 采多帧”（19 dot ≈139 帧），不是选点策略。

---

## 5. 关键修复：dot-level 残差

第一版把同一 dot 的多帧当成独立样本，残差模型在 20 个 dot 上过拟合，
worst 达到 **+38.98%**。改成每个 dot 一个残差样本后：

- 有效样本数 = dot 数（约 20），而不是帧数（约 140）；
- LOO λ / 标准化在 dot 级别进行；
- worst 从 +38.98% 降到 +13.3%（hybrid@20）。

这是 dot-level 主动校准必须做的统计修正。

## 8. 风险与待办

1. **探索性**：`n_affine=4`、`cov_weight=0.1`、DINO-only、K 列表都是在 test 上
   比较出来的；论文前必须按 subject 划 selection/eval，在 selection 上选配置，
   在 eval 上报最终数字。
2. **dot 目标近似**：用 dot 多帧 label 均值近似显示点坐标；真实系统里显示坐标已知，
   这一步可以去掉。
3. **固定 K**：还没有自适应 stopping；下一步用后验/期望误差决定停止。
4. **frames/dot**：当前用数据集全部约 7 帧/dot；真实 UI 的 dwell time 可能不同，
   需要按固定采集帧数重跑。
5. **worst 仍有 +13%**：集中在候选 dot 少、特征弱的会话；需要 gate/收缩或
   按 dot 数/特征可靠性自适应。
6. **expected error**：当前是 feature-diversity，不是直接最小化期望 cm 误差；
   下一步实现 expected error reduction，可能进一步超过 hybrid。
