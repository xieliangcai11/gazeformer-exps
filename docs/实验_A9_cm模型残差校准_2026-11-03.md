## 2. 代码审查：发现的“归一化时代”问题

### 2.1 对角仿射在 norm / cm 下等价

设 `p_norm = p_cm / W + 0.5`，则

```text
u_norm = s * p_norm + b
u_cm   = s * p_cm + [(s + 2b - 1) W / 2]
```

scale 完全相同，只有 bias 换单位。因此 **N0 ≈ C0 是理论预期**，不是 bug。
交接文档里“cm base + norm 残差（C2）会更好”的前提，在 base 层面不成立；
真正能改的是先验、support 覆盖、Huber 尺度、残差正则和特征。

### 2.2 已确认的代码问题

| 位置 | 问题 | 处置 |
|---|---|---|
| `new_input_calib.py:338-340` + `:382` | region 特征列顺序：训练 `[features, intercept, regions]`，测试 `[features, regions, intercept]` | 旧 `--regions` 结果不可信；新脚本修正为 `[features, regions, intercept]` |
| `new_input_calib.py:407,425` | `clip(corr, -0.15, 0.15)` 是 norm 单位，几乎不裁剪 | 新脚本默认 `0.02 norm` / `0.15 cm`；A4 证明放开 clip 会严重变差 |
| `new_input_calib.py:61-72` | support coverage 在 norm 3×3 上 | 16:9 屏幕 norm 格子不等物理面积；旧脚本未处理 |
| `meta_residual_calib.py:65-74` | source prior 全局平均 | 新脚本支持 orientation/device 条件化；实测 orientation 无增益 |
| `cm_space_calib.py:55-71` | Huber 用两轴共享 MAD scale | 新脚本支持 per-axis scale；实测增益约 0.0002 cm |
| `seq_bayes_calib.py:45-75` | `load_index` 没有 phi/IMU | `em` 的 `hypot(dx*W,dy*H)` 与 canonical cm 误差等价（旋转不改变范数） |
| `robust_calib.py:38-50` | per-axis Huber | 这是更合理的实现；已在新脚本复用 |

### 2.3 新脚本

```text
scripts/calibration/cm_residual_calib.py
```

新增/修正：

- canonical cm ↔ norm 显式转换（`to_cm` / `to_norm`）；
- raw / base / calibrated 同 heldout 口径；
- 多源特征：DINO16 + landmark21 + pose8（按全局 index row 对齐）；
- 残差目标按轴标准化，使 λ 跨空间可比；
- 闭式 LOO 选 ridge λ；
- per-axis Huber；
- 按 orientation/device 条件化 source prior；
- 正确列顺序的 2×2/3×3 region 特征；
- `--no-residual`（base-only 消融）、`--min-session-frames`（固定 K 曲线会话集）；
- 完整日志：输入文件大小/mtime、shape、有效数、丢弃原因、每会话/每 seed、
  λ/alpha/LOO/裁剪比例、跳过原因、maxrss、args JSON、summary JSON。

## 5. 消融

| 编号 | 配置 | calib cm | 相对 base | 变好 | 最差 |
|---|---|---:|---:|---:|---:|
| A0 | N1 baseline：DINO16，固定 λ=1.0，无 std/LOO | 1.1538 | −4.38% | 420/443 | +3.41% |
| A1 | +landmark+pose，仍固定 λ | 1.1514 | −4.58% | 421/443 | +7.87% |
| A2 | A1 + 目标标准化 + LOO λ | 1.1473 | −4.93% | 430/443 | +3.04% |
| A2d | DINO only + std/LOO | 1.1529 | −4.46% | 425/443 | +2.60% |
| A2lm | DINO+landmark + std/LOO | 1.1471 | −4.94% | 428/443 | +2.27% |
| A2p | DINO+pose + std/LOO | 1.1527 | −4.48% | 421/443 | +2.32% |
| A8r2 | A2lm + 2×2 region | 1.1475 | −4.91% | 427/443 | +2.77% |
| A8r3 | A2lm + 3×3 region | 1.1463 | −5.01% | 431/443 | +2.24% |
| **A9** | **A8r3 + per-axis Huber** | **1.1461** | **−5.00%** | **431/443** | +2.29% |
| A9b | A9 + `lam=0.1, delta=1.0` | 1.1449 | −4.87% | 429/443 | +3.02% |
| A3b | A2 + 软收缩 alpha | 1.1497 | −4.72% | 437/443 | +1.82% |
| A3 | A2 + 软收缩 + 硬 gate | 1.1498 | −4.72% | 437/443 | +1.82% |
| A6 | A2 + 硬 gate（无收缩） | 1.1619 | −3.71% | 412/443 | +2.60% |
| A4 | A2 + 分位数 clip | 1.1987 | −0.66% | 226/443 | +67.96% |

结论：

1. **目标标准化 + LOO λ 是残差部分最关键的改动**：A1→A2 把最差从 +7.87% 压回 +3.04%。
2. **landmark 有贡献**（DINO-only 1.1529 → DINO+landmark 1.1471）；**pose 没有贡献**。
3. **3×3 region 有小幅贡献**（1.1471 → 1.1463）。
4. **per-axis Huber 是噪声级改善**（1.1463 → 1.1461）。
5. **gate/收缩**把变好会话从 430 提到 437、最差降到 +1.82%，但总误差退到 1.1497；
   这是在“平均”和“最差”之间交换，不作为主结果。
6. **硬 gate 更差**（1.1619）：support LOO 在 K=50、37 维下不够可靠。
7. **分位数 clip 严重失败**（1.1987）：固定 `0.02 norm` clip 是重要正则，不能放开。
8. **先验按 orientation 条件化没有帮助**（base 1.2069 vs 1.2067）。

A9b 是当前最低（1.1449），但 `lam/delta` 是在 test 上看出来的，
**不作为主结果**；后续需用验证集选择。

## 10. 风险与后续

1. **A9 的配置选择使用了 test 消融**：features/regions/clip 是在 test 上比较的。
   论文前需要按 subject 划 selection/eval，在 selection 上选配置，在 eval 上报最终数字。
2. **A9b 不能作为主结果**：`lam/delta` 是 test 上试的。
3. **K=10 残差不可辨识**：37 维 > 10 个 support；需要减维或 DINO-only。
4. **base 仍是主要瓶颈**：raw→base 贡献 −24.2%，残差只再贡献 −5.0%。
   更大的杠杆是模型 raw 精度（按 `val_cm` 选模/续训）和更多标定点（K 曲线）。
5. **旧 `new_input_calib --regions` 结果不可信**：列顺序 bug，需重跑或废弃。
