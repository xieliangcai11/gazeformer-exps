# RGBDGaze 实验总结（2026-10-14）

本文档汇总当天在 RGBDGaze 上围绕**模型改进**与**误差场/个人标定**两条线所做的全部实验、

## 0. 结论摘要（先看这段）

### 可靠成果（成对确定性计算，不受 run 间波动影响）

1. **因果在线"层级误差场"标定**（零训练、零额外标注、严格只用过去帧）
   - RGBDGaze：**1.472 → 1.093 cm（−25.7%）**；**>3cm 从 7.86% 降到 ~3.5%（−55~68%）**
   - 距离"含未来信息"的泄漏上限（−27.1%）仅差 1.5–3 个点 ⇒ **该条已接近压满**
2. **误差"场"的存在性、稳定性、可解释份额**（两个数据集一致）
   - RGBDGaze：被试内 4×4 格场解释 **36%** 误差；前半 vs 后半场相关 **+0.86**
   - GazeCapture：同一测法解释 **~76%**（含时间泄漏，见 §4.3 修正）；跨半段相关 **+0.99**
3. **校准的"容量定律"**（两数据集一致）
   - 小预算时高容量灾难性过拟合：R=5% 时二次多项式 **+185%** ✗、仿射 +79.7% ✗、常数仅 +9.6% ✗
   - 大预算时高容量反超：R=30~50% 时仿射/二次 **−16.4%** ✓ 优于常数 −11.8%
   - ⇒ **最优容量随预算增长**（偏差-方差），与 Faze(2019) 自述"过参数化模型在少样本上迅速过拟合"同源
4. **眼支流的机制对照**（决定论文叙事）
   - 真实眼图 **1.472** ✓ ／ 无眼支流 **1.74** ／ **眼图打乱（同架构同算力）1.89** ✗✗
   - ⇒ 收益**来自与当前帧对齐的眼部内容**，不是参数量/算力/正则化

## 2. 模型线实验

### 2.1 眼支流机制：内容 vs 架构（对照实验）

三个模型**同配置、同 8 epoch、同全局 batch 24**，唯一差别是眼支流的处理方式：

| 模型 | test EM | 角均值 | ≤1.91° |
|---|---|---|---|
| 无眼支流 | 1.74 | 3.26° | 31.1% |
| **眼图打乱**（batch 维 roll 一拍：真实眼图、分布不变、算力相同）| **1.89** ✗✗ | 3.55° | 23.9% |
| 真实眼图 | **1.472** ✓✓ | 2.76° | 37.6% |

**结论**：打乱对齐后收益不仅消失、**还劣于无眼支流** ⇒ 收益 100% 来自**对齐的眼部内容**（虹膜细节），
"多一路输入/更多参数"贡献为 0。实现：`scripts/train.py --eye-shuffle`（`EYE_SHUFFLE` 全局 + `_shuffle_eyes`）。

### 2.2 眼部裁剪收紧（`--eye-scale`）

动机：眼支流收益既然来自内容，就应提高其**有效分辨率**。
原实现取眼框**长边**作正方形（186×53 的眼框 ⇒ 边长 186 ⇒ 虹膜仅占 28%）。
新增 `--eye-scale k`：边长 = k × 眼框高度，居中。`k=1.5` 时边长 80px ⇒ 虹膜占比 ~2/3、
等效虹膜像素 53 → ~190px（3.5×）。冒烟图确认对准、无背景、上下眼睑更清晰。
实现：`src/gazelab/datasets/rgbdgaze.py`（`eye_scale`）+ `scripts/train.py`（`--eye-scale`）。
运行：`eye224_s15`（224，其余与 ② 逐字相同）。

### 2.3 训练对照（进行中）

| 运行 | 与 ② 的唯一差别 | 目的 |
|---|---|---|
| `eye224_s15` | `--eye-scale 1.5` | 内容放大器是否有效 |
| `eye448_v1` | 224 → 448（6 卡 × batch 4 = 全局 24）| 分辨率 + 眼支流叠加 |
| `eye224_e16` | 8 → 16 epoch | ② 是否只是训练不足；**兼作 ② 的免费复制品** |

## 3. 误差场 / 个人标定线

### 3.1 数据协议的两个陷阱（重要）

1. **朝向陷阱**：历史 ckpt（`g5/g6/base224/g6_multi`）以 `np.rot90` 躺倒朝向训练。
   用错朝向评估**不报错**、只把 EM 抬高 2.5–3 倍（实测 `g6_multi`：raw 4.410 ✗ vs rot90 **1.638** ✓）。
   ⇒ 已在 `scripts/rgbdgaze/calibrate.py` 增加 `--orient {raw,rot90}`（默认 raw，含警告文本）。
2. **分布漂移**：每个 session **前 10–15%** 的注视分布与后段差 **3.8–5.5cm**（动画开场大幅扫视）。
   ⇒ 用"前段帧"做一次标定会**系统性崩坏**：实测 −174% / −82% / −30% ✗✗（漂移越大窗口越小越糟）。
   ⇒ 同 session 内**随机/交错**切分做标定还会**泄漏**（把测试分布当标定集）。

### 3.2 标定协议与偏移方案（同骨干 448，朝向已修正，基线自检 1.68cm ✓）

| 方案 | 5% 预算 | 10% | 15% |
|---|---|---|---|
| 前段划分 + 常数偏移（旧做法）| 4.59cm ✗✗（−174%）| 3.05 ✗ | 2.19 ✗ |
| **交错划分 + 常数偏移** | 1.45（13.5%）✓ | 1.41（15.9%）✓ | 1.39（17.1%）✓ |
| 交错划分 + 仿射（6 参）| 1.62（3.5%）✗ 不稳 | 1.41（16.1%）✓ | **1.35（19.2%）** ✓ |
| 交错划分 + 特征型逐帧偏移（~5 万参）| — | **2.36（−40.8%）** ✗✗ | — |

**结论**：① 划分方式是主因（−174% → +17%）；② **容量是关键**：高容量特征型偏移**主动有害**，
低容量（2–6 参）最优；③ 6 参仿射在 5% 预算下不稳（p31 从 2.54 崩到 4.17 ✗）。

### 3.3 容量定律（同脚本跨数据集）

| 校准预算 | 常数(2) | 仿射(6) | 二次(12) | 空间最近9帧 |
|---|---|---|---|---|
| R=5% | +9.6% ✗ | +79.7% ✗✗ | **+185%** ✗✗✗ | +7.6% ✗ |
| R=10% | +2.4% | +18.3% ✗ | +97.0% ✗✗ | +0.6% |
| R=30% | −11.5% | **−16.4%** ✓ | −15.3% | −9.0% |
| R=50% | −11.8% | −15.9% | **−16.4%** ✓ | −8.3% |

### 3.4 因果在线"误差场"（本线主结果）

严格因果（第 t 帧只用 t 之前的帧），零训练、零额外标注。
**索引键必须是"预测注视点"** —— 用真值当键是**另一个条件期望**，不是上界（实测更差 ✗）。

| 实现 | RGBDGaze EM | vs 基线 |
|---|---|---|
| 每格偏移 + 3×3 池化（G=4/6/8）| 1.115–1.121 | −23.8~−24.4% |
| 每格仿射（λ 扫描）| 1.115 | −24.2% |
| 仅全局仿射（每 session，每帧重解）| 1.138 | −22.7% |
| 全局二次/三次多项式 ± 每格残差 | 1.195–1.309 | −11~−19% ✗ |
| 角度空间（yaw/pitch 2°）± 时间衰减 | 1.164–1.178 | −20~−21% ✗ |
| 虹膜几何索引（可观测、零查询噪声）| 1.464 | **−0.5%** ✗✗ |
| **层级：全局仿射 → 每格残差偏移（G=8，3×3 池化）** | **1.093** | **−25.7%** ✓✓ |

**上界与缺口分解**（同一评估集）：

| 协议 | EM | vs 基线 |
|---|---|---|
| 不修正 | 1.454 | — |
| 离线场（仅前 30% 拟合）→ 后半段 | 1.280 | −11.9% ✗（早期是另一 regime，必然偏）|
| **因果在线场（现有方法）** | **1.108** | **−23.8%** ✓ |
| 整段拟合（含未来 ⇒ 泄漏参考）| 1.060 | −27.1% |

⇒ **因果版距泄漏上限仅 1.5–3 点** ⇒ 估计器与表示两个维度均已穷尽。
**预热曲线**（层级场）：0–200 帧 −16.9%、200–600 帧 −22.1%、600–1500 帧 −19.9%、1500+ 帧 −3.3%
⇒ **增益集中在模型本来较差的区段（天花板效应）**，正是"专治长尾"。

### 3.5 跨被试迁移（两次检验，均否定）

| 检验 | 结果 |
|---|---|
| LOSO（仅 4 个被试建场 → 第 5 人）| 常数/线性/二次/核平滑**全部变差** ✗✗（+5~27%）|
| **大规模：1262 训练被试建场 → 150 新被试** | 全部配置 **−0.6~−0.7%** ✗（覆盖率 100%，但毫无收益）|

⇒ **场是被试特异的**：被试内解释力强（36~76%）、跨被试**不可迁移**。
与文献调和：Faze/ELF-UA/Alfa 迁移的是**"如何适配"（特征/参数空间）**，不是**"误差本身"**。

## 4. 跨数据集验证（GazeCapture：1470 人 / 1.49M 帧 / 真实场景，划分跨被试：train 1263 人 / test 150 人 / 交集 0）

### 4.1 复现的结构性规律

| 规律 | RGBDGaze | GazeCapture |
|---|---|---|
| 预测系统性收缩（std(预测)/std(真值)）| 0.885 / 0.898 | **0.505 / 0.592** ✗✗ |
| 误差随离屏心距离增长 | 1.38 → 1.61 | **1.06（中心）→ 4.80（边缘）** ✗✗（4.5×）|
| 每被试常数偏置占其误差 | 中位 38.6% | 中位 **10.5%** ✗ |
| 被试内空间场解释份额（含时间泄漏 ✗）| 36.7% | 75.9% |
| 场跨半段稳定性 | +0.86 | **+0.99** |

### 4.2 两条 GC 特有的强系统效应

- **设备**：iPad 5.55–6.95cm ✗✗ vs iPhone 2.17–3.59cm ⇒ **该模型已带 geom token 仍差 2–3 倍**
  ⇒ "喂屏幕尺寸"远不足以消除设备偏差。
- **朝向**：orientation=2 的 EM **6.45cm**，其余 3.45–3.47 ⇒ 与 RGBDGaze 的"朝向差 2.5~3 倍"同源。

### 4.3 对既有表述的修正

- GC 的训练被试误差 **3.421** ≈ 测试被试 **3.625** ⇒ 该模型是**能力不足/欠拟合**（不是"记住人"），
  这也解释了它"被试级偏置占比低、任何标定都无效、收缩极端（0.505）"。
- 因此"每 session 一个常数偏置"应表述为：**"每个（被试 × 条件）的一张平滑误差场"**，
  其**零阶项**（常数偏移）在 RGBDGaze 显著（38.6%）、在 GC 的被试粒度上很小（10.5%）。
- 先前"离线 4×4 格留一 = −36.7%"含**时间泄漏**（用相邻帧预测相邻帧），**不是可拿上界**；
  诚实上界见 §3.4（含未来 −27.1%）。

### 4.4 适用边界（可写进论文的判据）

| 数据集 | 模型归一化误差 | 网格格宽 | 自索引场 |
|---|---|---|---|
| RGBDGaze | ~0.11–0.2 | 0.125（G=8）| **可用（−25.7%）** ✓ |
| GazeCapture | ~0.35–0.6 | 同 | **失效（−3%）** ✗ |

⇒ **自索引式免标注自适应的收益是模型自身归一化精度的函数；模型越好，校准越有效**（正向耦合）。

## 5. 方法学发现（影响后续所有结论的强度）

1. **run 间波动不可忽略**：*同一配置*（`eye224_e16` 与 ②）在 epoch 0 就相差 **0.37cm**；
   epoch 2 相差 0.05cm ⇒ **单 run / 单 epoch 的模型对比无效**，需完整曲线 + 最终 test，且需多 seed。
2. **成对确定性计算不受此影响**：误差场/标定的所有数字都是在**同一条固定预测流**上算的
   ⇒ **无 run 间波动** ⇒ 这些结论比模型线的差值可靠得多。
3. **评估朝向必须与训练一致**（§3.1），否则数字失真 2.5–3 倍且不报错。
4. **不要用"前段帧"做标定/评估**（§3.1），且**不要在同 session 内随机切分做标定**（泄漏）。
5. **吞吐**：同全局 batch 24 下，1 卡 × batch 24 ≈ 9–12 s/100 步；6 卡 × batch 4 ≈ 19.9 s/100 步 ✗
   （小 batch 的 DDP 固定开销占主导）⇒ 单个实验优先单卡大 batch；6 卡用于并行多实验。
   448 则相反：单卡 89 s/100 步 ✗ vs 6 卡 37 s/100 步 ✓（算力大时 DDP 划算）。

## 6. 已被否证的假设（诚实清单）

| 假设 | 结论 |
|---|---|
| "眼支流收益来自更多参数/算力/正则化" | **否定**（打乱眼图后劣于无眼支流）|
| "误差场可跨被试迁移（4 被试失败只是规模问题）" | **否定**（1262 训练被试仍 −0.6%）|
| "只要喂屏幕几何就能消除设备偏差" | **否定**（GC 带 geom token 仍差 2–3 倍）|
| "稀疏标定（每 20 秒 0.17 秒）可得 −26.8%" | **否定**（该数字来自 oracle 查询 + 未来帧泄漏；公平口径下 4% 预算 ≈ 0）|
| "用真值注视点作索引是上界" | **否定**（那是另一个条件期望，实测更差）|
| "离线 4×4 格留一 −36.7% 是可达上界" | **否定**（含时间泄漏；含未来上界为 −27.1%）|
| "误差场需要 1 秒内刷新" | **修正**：短时间窗只是**隐含**了空间局部性；真正约束是索引精度 |
| "条件粒度（被试×朝向）能救回 GC" | **否定**（细分后仍 ≈0）|
| "虹膜相对位置可作零噪声索引" | **否定**（30cm/小屏下眼球转动极小 ⇒ 信噪比不足，−0.5%）|

## 7. 未决与下一步

1. **模型线三对照**（进行中）：`eye224_s15` / `eye448_v1` / `eye224_e16`

4. **误差场线**：估计器与表示已穷尽，**不再新增实验**；剩余空间通过"更好的模型"获得（正向耦合）

### 9.5 今晚确立的"故事"（一句话）

> **模型在新被试上的残余误差，几乎全部是"被试特异的系统性结构"（偏置 + 尺度 + 空间误差场），而不是随机噪声。**
> 它**不可跨被试迁移**（4 被试 LOSO ✗；尺度校正 5 折全部变差 ✗；1262 被试那次因坏 checkpoint 作废、重新开放），
> 也**无法靠改架构/输入消除**（448 ✗、收紧眼部裁剪 ✗、角度空间 ✗、多项式 ✗、虹膜几何 ✗）；
> 但**只用该被试自身极少量数据**，一个 **2–8 参数、零训练、严格因果**的在线修正即可吃掉
> **≈25% 的均值误差与 ≈57% 的长尾**，且在 RGBDGaze 三个模型上增益一致稳定 ✓✓。
> 该修正在原理上受"索引精度"限制（索引 = 模型自己的预测）。
> ⇒ ⇒ **固有缺陷 = 跨被试泛化（被试特异的系统性误差场）；可靠解法 = 自索引在线场（已达成）＋ 把模型本身的跨被试泛化做强（待做）**。
